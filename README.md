# 局域网文件传输

这是一个适合 Windows 和 Mac 混用的局域网文件传输小程序。选一台电脑运行 `lan_file_hub.py`，其他电脑用浏览器打开它显示的地址，就可以互相上传、下载文件。

## 你的网络应该这样用

你的网络里有一部分电脑直接接在光猫/交换机上，另一部分电脑在“交换机后面再接一个路由器”的 Wi-Fi 下。这个 Wi-Fi 路由器如果是普通路由模式，网线电脑通常不能主动访问 Wi-Fi 电脑，但 Wi-Fi 电脑一般可以主动访问上层网线电脑。

所以最稳的方式是：

1. 在“直接接光猫/交换机”的其中一台电脑上运行这个程序。
2. 其他电脑，包括 Wi-Fi 下的电脑，都打开运行窗口里显示的地址，例如 `http://192.168.50.214:8765`。
3. 所有人通过同一个网页上传和下载文件。

如果你把 Wi-Fi 路由器改成 AP/桥接模式，所有电脑会更像在同一个网段里，访问会更简单；但这个程序不要求你必须改路由器。

## Windows 运行

先安装 Python 3。安装时勾选 `Add python.exe to PATH`。

然后双击：

```text
start_windows.bat
```

如果 Windows 防火墙弹出提示，请允许 Python 在“专用网络”中通信。

## Mac 运行

打开终端，进入这个文件夹后运行：

```bash
python3 -B lan_file_hub.py
```

也可以运行：

```bash
./start_mac.command
```

如果提示没有执行权限，运行：

```bash
chmod +x start_mac.command
```

## 使用方法

1. 程序启动后会显示两个地址。
2. 本机打开 `http://127.0.0.1:8765`。
3. 其他电脑打开 `http://这台电脑的IP:8765`。
4. 在网页里点击选择文件，或把文件拖进去上传。
5. 列表里的文件可以被其他电脑下载，也可以删除。

上传的文件默认保存在：

```text
shared_files
```

## 常见问题

如果其他电脑打不开地址，优先检查这几件事：

1. 运行程序的电脑不要休眠。
2. Windows 防火墙允许 Python 通信。
3. Wi-Fi 电脑访问的是“直接接光猫/交换机那台电脑”的 IP。
4. 如果 Wi-Fi 路由器开了“访客网络”或“AP 隔离”，请关闭，否则 Wi-Fi 设备可能无法访问局域网内其他设备。
5. 换一个端口运行，例如：

```bash
python3 -B lan_file_hub.py --port 8888
```
